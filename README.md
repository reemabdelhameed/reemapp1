# reemapp1
Overview
A cross-platform mobile application built using Flutter that allows users to securely create, manage, and store notes in real time.

Features:
User authentication (Sign up, Login, Email Verification)
Create, read, update, and delete notes (CRUD)
Cloud storage using Firebase Firestore
Secure user-based data access
Responsive and clean UI
Real-time updates using streams
State management using Bloc

Tech Stack:
Flutter (Dart)
Firebase Authentication
Cloud Firestore
Bloc (State Management)
Git & GitHub

What I Learned:
Mobile app architecture and state management
Backend integration using Firebase
Handling authentication and user sessions
Debugging and structuring scalable code

Status:
In Development – continuously improving features and performance
